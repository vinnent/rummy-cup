# Rummy Cup Samen

Rummikub voor twee op één apparaat. Na je beurt geef je het door; je stenen blijven verborgen tot de ander op **Toon mijn stenen** tikt. Met de huisregel voor dubbele stenen, emoji-stickers van de jury en een regenboog voor de winnaar.

Spelen: <https://vinnent.github.io/rummy-cup/>

## Offline (bijvoorbeeld in het vliegtuig)

1. Open de link hierboven in Safari, met internet.
2. Tik op de deelknop en kies **Zet op beginscherm**.
3. Open de app één keer vanaf je beginscherm terwijl je nog internet hebt.

Daarna werkt hij ook in vliegtuigmodus. Een lopend spel wordt op het apparaat bewaard.
